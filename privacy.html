プライバシーポリシー（セワシ式 自己分析ツール）

最終更新：2026年10月11日

1. だれが使うツールか

このツールは、YouTube のゲーム実況者「セワシ」本人だけが、本人のパソコンで使う分析ツールです。ほかの人がログインして使うことは想定していません。

2. 読み取るデータ

Google のログインで本人が許可した、次の読み取り専用の権限だけを使います。

  • YouTube Analytics の読み取り（https://www.googleapis.com/auth/yt-analytics.readonly）：本人のチャンネルの視聴回数・視聴時間・同時視聴者数・維持率・流入元・インプレッションとクリック率・登録者の増減など
  • YouTube アカウントの読み取り（https://www.googleapis.com/auth/youtube.readonly）：ログインしたアカウントが本人のチャンネルかどうかの確認と、本人の動画の一覧

収益の情報、他の人のチャンネルの非公開の情報は読みません。動画の投稿・変更・削除はしません。

3. データの使い方

読み取った数字は、本人が自分の動画づくりを振り返り、次に作る企画を決めるためだけに使います。広告や、ほかの目的には使いません。

4. データの保存場所

読み取った数字とログインのトークンは、本人のパソコンの中だけに保存します。外部のサーバーには送りません。

5. データを渡す相手

だれにも渡しません。売ることもありません。

6. Google API サービスのユーザーデータに関するポリシー

このツールが Google API から受け取った情報の使用と、ほかのアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。

7. 許可の取り消しとデータの削除

許可はいつでも Google アカウントの「サードパーティのアプリとサービス」 から取り消せます。保存したデータは、本人がパソコンの中のツールのフォルダから消せば、すべて消えます。

8. お問い合わせ

このページについての問い合わせは、YouTube チャンネル「セワシ」（https://www.youtube.com/channel/UCIKGnWED92bUOlXIYSvFXFw）からお願いします。

English summary

This is a personal, local-only tool used only by the YouTube creator Sewashi. It requests read-only scopes (yt-analytics.readonly, youtube.readonly) to read his own channel analytics and verify the channel. Data and tokens are stored only on his own computer, are used only to review his own videos, and are never shared, sold or sent to any server. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at https://myaccount.google.com/permissions.
